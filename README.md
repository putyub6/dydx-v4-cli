## Features

- Venue dydx / BTC-USD
- Strategy id perp
- Paper engine and stub candles
- Risk cap on notional / equity

## Prerequisites

- Go 1.22+
- Git

## Getting Started

```bash
git clone <repo-url>
cd dydx-v4-cli
make build
./bin/dydxv4 -help
```

## CLI Usage

```bash
make test
go run ./cmd/dydxv4 -help
```
